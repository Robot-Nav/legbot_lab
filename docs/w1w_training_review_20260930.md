# W1W 模型到训练链路复核（2026-09-30）

## 结论与边界

本次检查覆盖当前 `w1w_wf.urdf`、Isaac URDF 导入、碰撞过滤、执行器、动作与观测、重置、命令与奖励课程、CTS/PPO、恢复训练、播放及导出。下列代码问题已修复，并有 CPU 回归和实际仿真证据。

**PhysX GPU 随机失败仍未解决。** 2048 环境原运行在第 170 轮发生 CUDA 700；本次修改后从 `model_150.pt` 续训，在第 184 轮发生 CUDA 719。不能保证减少环境数、修改 URDF 或本次优化可以根治它。新增错误处理解决的是已抛出异常后进程卡在 native 析构的问题，不是 CUDA 错误本身，也不能处理所有无异常的底层死锁。

本次未修改 `w1w_deploy` 或两个 URDF 的几何/质量参数。

## 模型检查

- 简化模型包含 17 个 link、16 个关节，总质量约 38.9424 kg，右前轮为 `fr_foot_joint`。
- 质量、质心、惯量和关节/视觉坐标补偿保留原始模型数据；惯量正定并符合主惯量三角不等式。
- 直接打开本次 Isaac 生成的 `/tmp/IsaacLab/usd_20260930_153130_1824/w1w_wf.usd`，17 个刚体的质量、质心和主惯量与源 URDF 匹配。检查的是导入资产，训练启动后的域随机化会按配置改变部分参数。
- 四轮在简化 URDF 中为 continuous，腿关节限位有效；MuJoCo 与 URDF 的关节轴、质量、质心、惯量和简化碰撞几何匹配。
- 16 对相邻刚体显式排除碰撞。几何测试另外绕过相邻和同体过滤，检查站姿、零位及 32 个附近姿态；测试通过不代表任意关节极限姿态都无自碰撞。
- 原始网格模型仍保留为 `RobotLab-Legbot-Original-v0`。其凸包导入会填平凹陷，之前出现过几乎每步 base illegal_contact；原始模型短测试退出正常不能证明其训练有效。

## 修复清单

| 部分 | 发现的问题 | 修改 |
|---|---|---|
| 默认任务 | 默认别名仍指向原始网格模型 | `RobotLab-Legbot-v0` 与 `RobotLab-Legbot-Simplified-v0` 均指向当前简化模型 |
| 默认数量 | 省略参数会生成 16384 环境 | 改成用户选择的 2048；这不代表已通过长期稳定性验证 |
| 随机重置 | 腿角乘 0.5～1.5，会在出生时穿地 | 缩小为 0.9～1.1；保留其他域随机化 |
| 策略观测 | single_obs 与 policy 最新帧各自加独立噪声；轮角零占位被加噪声 | single_obs 从 policy 最新帧提取；四个轮角占位在所有历史帧保持零 |
| 显存 | `list(generator)` 把所有 epoch 的小批次复制到显存并保留 | PPO 和蒸馏分别流式遍历；学生仍在 PPO 完成后更新 |
| CTS 划分 | 模运算只支持少数教师比例/环境数量 | 按精确数量均匀分布学生环境，验证两类小批次非空 |
| 数值检查 | 标量标准差可能非正；非有限梯度可污染后续权重 | 分布尺度设置正下限；优化器更新前检查梯度有限性 |
| 多卡路径 | 学生蒸馏梯度没有同步，旧学生梯度可能进入下一轮 PPO 归约 | 清除旧梯度并同步学生梯度；本次实际仿真仅验证单卡 |
| 恢复训练 | optimizer 学习率恢复，但算法的 adaptive 学习率变量未恢复 | 同步恢复；保留已有 next_iter/common_step_counter 恢复机制 |
| 平滑奖励 | 用上一步动作非零判断是否刚重置，合法零动作被漏罚 | 用 episode 步数跳过前两步 |
| 零命令 | 停止平移后仍保留随机 yaw | 先清零全部命令，再按设定概率添加原地转向 |
| 极限命令反向 | 反转的是刚采样的命令 | 反转上一次的命令 |
| 课程与设备 | reward 课程固定除以 24；设备参数只改仿真端 | 将真实 rollout 长度同步给课程；CLI 设备同步至 learner |
| 最终速度课程 | 3 m/s 阶段从第 100000 轮开始，恰好训练十万轮无法训练该阶段 | 调到第 75000 轮，保留前面 20000/50000 阶段 |
| 运行配置 | runner 会 pop 掉调用方字典里的 class_name；诊断参数没写入快照 | runner 拷贝配置；保存实际入口配置（含诊断参数） |
| 错误日志 | Python stderr 未保留，初始化输出没进 train.log | 创建环境前开始记录 stdout/stderr；启动打印资产和设备 |
| GPU 失败退出 | 抛出后端错误后可能卡在原生析构 | 写 fatal_error.log，flush/fsync 后以代码 1 退出；不从已失败的 CUDA 上下文保存新模型 |
| 无日志运行 | 无条件构造周期保存路径；分布式其他 rank 也可能保存 | 仅有效日志目录与主 rank 保存 |
| 播放导出 | 单环境播放仍构造 CTS 训练器和 rollout 缓冲 | CTS 播放直接加载网络；支持 num_envs=1 |
| 播放参数 | disable_fabric/video_length 没有落实到执行路径 | 接通参数，增加 max_steps；同步设备并创建视频目录 |

### 重置几何证据

使用原始质量和当前简化几何，在最低出生高度 z=0.53、平地且 base 竖直条件下采样 1000 个姿态：

- 旧范围：57.3% 的姿态至少一个轮子低于地面，最深约 4.50 cm。
- 新范围：抽样全部离地，最小间隙约 7.03 mm；另对 8 个 thigh/calf 独立倍率的 256 种端点组合回归检查，轮底间隙均大于 5 mm。

这是最低出生高度的几何检查，不是实际全部 reset 的碰撞概率；真实 reset 还随机增加 0～5 cm 高度。起伏地形也不能套用平地保证。

### 接口保留

动作依然为 FL、FR、RL、RR 每腿 hip/thigh/calf/wheel，16 维；观测单帧 57 维、4 帧按观测项堆叠为 228 维。腿动作比例 0.25、轮速比例 20、raw action 截断 ±10、轮速目标 ±150、控制周期 0.02 s，与现有部署保持接口一致。没有把 URDF 中 FR 的特殊坐标补偿强行镜像。

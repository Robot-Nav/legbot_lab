# Legbot RL Lab 项目分析

Legbot RL Lab 是基于 NVIDIA Isaac Lab 的 Legbot 四足机器人强化学习训练与部署项目，覆盖从仿真训练到实物控制的完整链路。

## 1. 项目定位

项目包含两条主线：

- **训练（Python）**：Isaac Lab + RSL-RL PPO，输出 `model_*.pt`、TorchScript `policy.pt` 和 ONNX `policy.onnx`。
- **部署（C++）**：ONNX Runtime + FSM 状态机，同一套代码通过 `Sim2SimInterface` 对接 MuJoCo 仿真器，通过 `Sim2RealInterface` 控制真实机器人。

仓库根目录 `legbot_mujoco` 同时包含：

- `simulate/`：基于 MuJoCo + Unitree SDK2 DDS 的仿真器，用于 Sim2Sim 验证。
- `legbot/`：基于 `motrix_envs` 框架的导航训练环境，与 Isaac Lab 训练方案并行存在。
- `unitree_robots/`：Go2 等 Unitree 机器人的 MJCF 模型。

## 3. 训练流程

入口：`scripts/rsl_rl/train.py`

1. 解析命令行参数与 `cli_args.py`。
2. 通过 `AppLauncher` 启动 Isaac Sim。
3. `gym.make(task_name, cfg=env_cfg)` 创建 MDP 环境。
4. `RslRlVecEnvWrapper` 适配到 RSL-RL。
5. `OnPolicyRunner` 执行 PPO 训练。
6. `export_deploy_cfg()` 自动导出 `params/deploy.yaml`。

推理与导出入口：`scripts/rsl_rl/play.py`

1. 加载 `model_*.pt`。
2. 在 Isaac Sim 中运行 PyTorch 推理演示。
3. 导出 `exported/policy.onnx`（C++ 部署）和 `exported/policy.pt`（Python 推理）。

三种模型文件：

| 文件 | 格式 | 用途 |
|------|------|------|
| `model_*.pt` | 完整训练状态 | 继续训练 / 恢复 |
| `exported/policy.pt` | TorchScript | Python 推理 |
| `exported/policy.onnx` | ONNX | C++ ONNX Runtime 推理 |

## 4. Legbot 环境配置

### 4.1 观测空间（Policy）

| 观测 | 维度 | 缩放 | 噪声 | 说明 |
|------|------|------|------|------|
| base_ang_vel | 3 | 0.2 | ±0.2 | IMU 角速度（rad/s） |
| projected_gravity | 3 | 1.0 | ±0.05 | 机体坐标系下重力投影 |
| velocity_commands | 3 | 1.0 | 无 | 目标 $v_x, v_y, \omega_z$ |
| joint_pos_rel | 12 | 1.0 | ±0.01 | 相对默认位置的关节位置 |
| joint_vel_rel | 12 | 0.05 | ±1.5 | 关节速度 |
| last_action | 12 | 1.0 | 无 | 上一时刻动作 |

总维度：45。

Critic 额外包含 `base_lin_vel`（3）和 `joint_effort`（12）。

### 4.2 动作空间

采用关节位置目标模式：

```python
q_target = default_joint_pos + 0.25 * action
```

- `default_joint_pos`：`[0.0, 0.9, -1.8] × 4`
- `scale = 0.25`
- 动作输出无额外裁剪（`clip = (-100, 100)`，实际无影响）

### 4.3 主要训练参数

- 并行环境数：4096
- 物理步长：0.005s，decimation = 4，策略频率 50Hz
- episode 长度：20s
- 网络结构：Actor / Critic 均为 `[512, 256, 128]`，ELU 激活
- PPO：clip = 0.2，γ = 0.99，λ = 0.95

## 5. 算法与训练细节

### 5.1 PPO + GAE

使用 RSL-RL 实现的近端策略优化（PPO）：

- 重要性采样比：

  ```
  r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)
  ```

- Clipped surrogate 目标：

  ```
  L^CLIP(θ) = E_t[ min( r_t(θ) A_t, clip(r_t(θ), 1-ε, 1+ε) A_t ) ]
  ```

- 广义优势估计（GAE）：

  ```
  δ_t = r_t + γ V(s_{t+1}) - V(s_t)
  A_t = Σ_l (γλ)^l δ_{t+l}
  ```

- 总损失：

  ```
  L = L^CLIP - c1 L^VF + c2 H(π)
  ```

### 5.4 域随机化

训练时通过 `EventCfg` 注入不确定性：

| 随机化项 | 范围 | 模式 |
|----------|------|------|
| 静/动摩擦系数 | 0.3–1.2 | startup |
| 恢复系数 | 0.0–0.15 | startup |
| base 附加质量 | -1.0–+3.0 kg | startup |
| 随机推拽速度 | x,y ∈ [-0.5, 0.5] m/s | interval 5–10s |
| 重置时 root 位置 | x,y ∈ [-0.5, 0.5] m, yaw ∈ [-π, π] | reset |
| 重置时关节速度 | -1.0–1.0 rad/s | reset |

### 5.5 命令与课程

- 速度命令每 10s 重新采样。
- 训练范围：$v_x, v_y \in [-0.1, 0.1]$ m/s，$\omega_z \in [-1, 1]$ rad/s。
- 限制范围：$v_x \in [-1.0, 1.0]$，$v_y \in [-0.4, 0.4]$，$\omega_z \in [-1.0, 1.0]$。
- 课程学习：
  - `terrain_levels_vel`：根据速度表现自动调整地形难度。
  - `lin_vel_cmd_levels`：根据训练进度放宽线速度命令范围。

### 5.6 终止条件

- `time_out`：达到 episode 长度 20s。
- `base_contact`：base 受到大于 10N 的非法接触。
- `bad_orientation`：roll/pitch 超过 0.8 rad。

## 6. C++ 部署架构

```
main.cpp
├── Sim2SimInterface  → DDS LowCmd / LowState
└── Sim2RealInterface → USB 串口 + RobStride 电机 + IMU

CtrlFSM (1kHz)
├── Passive    → 低刚度 / 阻尼
├── FixStand   → 线性插值到站立姿态
└── Velocity   → State_RLBase 加载 policy.onnx 推理
```

`State_RLBase` 在独立线程中以 50Hz 运行：

1. `robot->update()` 读取关节与 IMU 状态。
2. `observation_manager->compute()` 生成观测。
3. `OrtRunner::act(obs)` 执行 ONNX 推理。
4. `action_manager->process_action()` 生成关节目标。

FSM 主循环将目标写入 `motor_cmds`，最终通过 `interface->send_cmd()` 下发。

## 7. Sim2Sim（MuJoCo）

MuJoCo 仿真器位于 `legbot_mujoco/simulate/`。

- 加载 `legbot/xmls/scene.xml`（Legbot 场景）。
- `legbot_bridge.h` 订阅 `rt/lowcmd` 写入 MuJoCo `ctrl`，读取 MuJoCo 传感器发布 `rt/lowstate`。
- 支持 Xbox / Switch / 键盘三种输入方式。
- 仿真器本身不加载策略；策略推理运行在独立的 `legbot_ctrl` 进程中，通过 DDS 与仿真器通信。

典型启动方式：

```bash
# 终端 1：启动 MuJoCo 仿真器
cd legbot_mujoco/simulate/build
./unitree_mujoco

# 终端 2：启动控制器
cd legbot_rl_lab/deploy/robots/legbot/build
./legbot_ctrl --mode sim2sim --network lo
```

## 8. Sim2Real

真实机器人接口 `Sim2RealInterface` 位于 `deploy/robots/legbot/include/Types.h`。

- 双串口控制 12 个 RobStride 电机：
  - `/dev/ttyUSB0`：FR + FL（6 电机）
  - `/dev/ttyUSB1`：RR + RL（6 电机）
- `/dev/ttyUSB2`：自制串口 IMU，输出欧拉角 + 角速度。
- `zero_offsets` 在发送时加上、读取时减去，实现仿真与物理角度对齐。

当前限制：

- `get_joystick()` 返回 `nullptr`，速度指令无法从手柄/键盘获取。
- 仅注册 `bad_orientation()` 安全检查，缺少力矩限制、关节限位、通信超时保护。

## 9. 关键配置文件

### `deploy/robots/legbot/config/config.yaml`

- FSM 状态定义与转换条件（手柄 DSL）。
- `Passive` / `FixStand` 的 PD 参数与站立插值轨迹。
- `Velocity.policy_dir`：指向训练输出的 `exported/policy.onnx`。
- `sim2real` 块：串口、CAN ID、IMU、零位偏移。

### `logs/rsl_rl/unitree_legbot_velocity/<run>/params/deploy.yaml`

由 `export_deploy_cfg.py` 在训练时自动生成，包含：

- `joint_ids_map`
- `default_joint_pos`、`stiffness`、`damping`
- 动作缩放、观测缩放
- 速度指令范围

## 11. 已知问题与后续工作

- Sim2Real 模式缺少遥控输入实现。
- 安全机制需要补充：力矩裁剪、关节软限位、通信超时切换 Passive。
- `legbot_rl_lab/legbot/` 目录在当前版本中不存在；`legbot/` 导航环境位于仓库根目录，使用独立的 `motrix_envs` 框架。
- legbot_mujoco 仿真器默认加载 Legbot 场景，已支持 Legbot Sim2Sim 验证。
